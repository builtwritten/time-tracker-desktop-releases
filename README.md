# Time Tracker Desktop — releases

Installers and the auto-update feed for the Time Tracker desktop app.
The source code lives in a private repository; this one only holds release files.

**Download for Windows:** [Time-Tracker-Setup.exe](https://github.com/builtwritten/time-tracker-desktop-releases/releases/latest/download/Time-Tracker-Setup.exe)

Installed apps update themselves from the releases here.

The installer is not code-signed yet, so Windows shows *Windows protected your PC* on first run: click **More info**, then **Run anyway**.
